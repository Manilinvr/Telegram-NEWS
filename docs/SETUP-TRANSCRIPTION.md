# Расшифровка видео

Транскрипция необязательна. При её отсутствии событие всё равно создаётся,
а транскрипция помечается как недоступная — конвейер не останавливается.

## Требование: ffmpeg

Для извлечения аудио и определения длительности нужен ffmpeg:

```bash
# Debian / Ubuntu
sudo apt install ffmpeg

# macOS
brew install ffmpeg
```

Если ffmpeg установлен не в `PATH`:

```
FFMPEG_PATH=/usr/local/bin/ffmpeg
FFPROBE_PATH=/usr/local/bin/ffprobe
```

Без ffmpeg видео сохраняется и показывается, но длительность не
определяется, а транскрипция помечается как недоступная.

## Провайдеры

### `none` (по умолчанию)

Транскрипция отключена.

### `whisper-cpp` — локально, без сети

Полностью офлайновый вариант: аудио не покидает сервер.

```bash
git clone https://github.com/ggerganov/whisper.cpp
cd whisper.cpp && make
bash ./models/download-ggml-model.sh medium
```

```
TRANSCRIPTION_PROVIDER=whisper-cpp
WHISPER_CPP_BIN=/opt/whisper.cpp/main
WHISPER_CPP_MODEL=/opt/whisper.cpp/models/ggml-medium.bin
TRANSCRIPTION_LANGUAGE=ru
```

Для русского языка модель `medium` даёт заметно лучший результат, чем
`base`, но требует больше памяти и времени.

### `openai-compatible` — HTTP-сервис

Подходит и для собственного развёртывания (faster-whisper с HTTP-обёрткой),
и для совместимых сервисов. Адрес задаётся явно, поэтому данные можно не
выпускать за пределы контура.

```
TRANSCRIPTION_PROVIDER=openai-compatible
TRANSCRIPTION_API_URL=http://localhost:9000/v1/audio/transcriptions
TRANSCRIPTION_API_KEY=            # если требуется
TRANSCRIPTION_MODEL=whisper-1
```

### `mock`

Детерминированная заглушка для тестов и приёмки: позволяет проверить весь
путь «видео → транскрипция → цитаты в карточке» без установки моделей.

## Ограничения

```
TRANSCRIPTION_MAX_DURATION_SECONDS=900
```

Видео длиннее лимита пропускаются: расшифровка часового эфира заняла бы
несоразмерно много ресурсов и почти не влияет на новостную ценность.

## Как обрабатываются неразборчивые фрагменты

Фрагменты с низкой уверенностью распознавания помечаются как
`[неразборчиво]` и **не додумываются**. Это принципиально: правдоподобная
выдумка в цитате очевидца хуже явного пропуска.

Полная транскрипция доступна в карточке события и **не обязана** попадать
в Telegram-пост — в публичный черновик идут только отобранные смысловые
фрагменты.
