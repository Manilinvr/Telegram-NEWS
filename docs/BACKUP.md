# Резервное копирование и восстановление

## Что нужно сохранять

| Что | Где | Критичность |
|---|---|---|
| База данных | PostgreSQL | **Критично** — вся история и настройки |
| Медиафайлы | `STORAGE_LOCAL_PATH` или бакет S3 | Важно — фото и видео событий |
| `.env` | Файловая система | **Критично** — секреты, не хранятся больше нигде |

Файл `.env` не входит в резервную копию БД и не коммитится в репозиторий.
Храните его в менеджере секретов: при утрате `SESSION_SECRET` все сессии
станут недействительными, а подписанные ссылки на медиа перестанут
проверяться.

## Копирование

```bash
npm run backup
```

Скрипт создаёт сжатый дамп в `BACKUP_DIR` (по умолчанию `./backups`) и
удаляет копии старше `BACKUP_RETENTION_DAYS` (по умолчанию 14 дней).

Вручную:

```bash
pg_dump "$DATABASE_URL" --format=custom --file=backup.dump
```

### По расписанию

```cron
# Ежедневно в 03:30
30 3 * * * cd /opt/nnm && npm run backup >> /var/log/nnm-backup.log 2>&1
```

Копии следует хранить **вне того же сервера**: локальная копия не спасает
от отказа диска.

## Восстановление

```bash
npm run restore -- ./backups/nnm-2026-04-14-033000.dump
```

Вручную:

```bash
dropdb nnm && createdb nnm
pg_restore --dbname="$DATABASE_URL" --no-owner backup.dump
npm run migrate    # добить миграции, появившиеся после копии
```

Восстановление **перезаписывает** базу. Скрипт запрашивает подтверждение.

## Медиа

При `STORAGE_DRIVER=local`:

```bash
tar -czf media-$(date +%F).tar.gz storage/media
```

При `STORAGE_DRIVER=s3` пользуйтесь средствами хранилища (версионирование
бакета, репликация).

Потеря медиа не нарушает целостность базы: записи сохраняют оригинальные
ссылки, и файл при необходимости можно скачать заново, пока ссылка
действительна.

## Проверка копии

Копия, которую ни разу не восстанавливали, — это предположение, а не
резервная копия. Раз в несколько месяцев:

```bash
createdb nnm_restore_test
pg_restore --dbname=postgres://user@host/nnm_restore_test --no-owner backup.dump
psql nnm_restore_test -c "SELECT count(*) FROM events;"
dropdb nnm_restore_test
```
