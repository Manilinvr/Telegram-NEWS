# Подключение источников

## Telegram

У Telegram нет одного хорошего способа читать чужие публичные каналы.
Реализованы два официальных пути, и выбор между ними — это выбор
компромисса. Режим задаётся переменной `TELEGRAM_INGEST_MODE`.

### Режим `bot` — Bot API

Полностью официальный интерфейс. Ограничение принципиальное: **Telegram не
даёт ботам читать историю канала**. Бот получает только новые публикации и
только там, где он добавлен участником.

Подходит для: **ваших собственных каналов**.
Не подходит для: чужих каналов, куда вас не добавят администратором.

Настройка:

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Добавьте бота в канал как администратора (достаточно права читать).
3. В `.env`:
   ```
   TELEGRAM_INGEST_MODE=bot
   TELEGRAM_BOT_TOKEN=123456:AA...
   ```
4. Добавьте источник в разделе «Источники», указав `@username` канала.

История канала при этом не загрузится: накопление начнётся с момента
подключения.

### Режим `public-preview` — публичная страница предпросмотра

Telegram сам публикует страницу `t.me/s/<канал>` без авторизации — именно
для просмотра открытых каналов. Адаптер читает её.

Ограничения и правила, которые система соблюдает:

- Никакие защиты не обходятся: нет обхода авторизации, CAPTCHA, приватных
  чатов и технических ограничений.
- Запросы редкие, User-Agent честный и идентифицирует систему.
- **Если канал отключил предпросмотр, он не читается** другим способом.
  Это прямое указание владельца канала, и оно уважается — адаптер сообщит
  об этом в разделе «Источники» и остановится.
- Доступен небольшой объём недавних публикаций, а не весь архив.

Настройка:

```
TELEGRAM_INGEST_MODE=public-preview
```

Токен не нужен. Добавьте источник с `@username` канала.

### Режим `none`

Telegram-источники отключены. Используйте, если работаете только с VK.

### Режим `mtproto`

Переменные (`TELEGRAM_API_ID`, `TELEGRAM_API_HASH`) предусмотрены, но
клиент MTProto в поставку не входит — см.
[LIMITATIONS.md](LIMITATIONS.md). При выборе этого режима система работает
через `public-preview`.

## VK

Используется официальный метод API `wall.get` с сервисным ключом доступа.
Читаются только **открытые** стены: закрытые сообщества требуют прав,
которых у сервисного ключа нет, и попытки их получить не предпринимаются.

Настройка:

1. Создайте приложение на <https://vk.com/apps?act=manage> (тип
   «Standalone» или «Веб-сайт»).
2. В настройках приложения скопируйте **сервисный ключ доступа**.
3. В `.env`:
   ```
   VK_ACCESS_TOKEN=vk1.a....
   VK_API_VERSION=5.199
   ```
4. Добавьте источник, указав короткое имя сообщества (из адреса
   `vk.com/<имя>`) или числовой `owner_id`.

## Настройки источника

Каждому источнику можно задать (раздел «Источники» либо поле `config`):

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `pollIntervalSeconds` | 60 | Как часто опрашивать. Минимум 15 с. |
| `fetchLimit` | 50 | Сколько публикаций забирать за раз |
| `backfillHours` | 48 | Глубина первого импорта |
| `skipForwards` | false | Пропускать пересылки |
| `minTextLength` | 0 | Минимальная длина текста для создания события |

## Проверка доступности

Источник проверяется **до** сохранения: если канал недоступен или закрыл
предпросмотр, он не будет добавлен, и вы сразу увидите причину. Так в
списке не появляются источники, которые никогда ничего не отдадут.

## Что происходит при сбое источника

Отказ одного источника не влияет на остальные. Источник постепенно
деградирует: `HEALTHY` → `DEGRADED` (единичные сбои) → `FAILING`
(пять подряд). Автоматически он **не отключается** — временная
недоступность платформы не должна молча привести к потере канала. Ошибки
видны в карточке источника и в разделе «Аналитика».

## Правовая сторона

Система сохраняет для каждой публикации источник, оригинальную ссылку и
сведения о медиа. Переработанный чужой материал **не** считается
автоматически свободным для перепубликации: указание источника добавляется
в каждый готовый пост и не может быть отключено. Ответственность за
соблюдение прав правообладателей при публикации остаётся на владельце
системы.
